# Справочник ГНМ

Приложение для iPhone (веб-приложение, ставится на экран «Домой»). Поиск по базе органов и тканей: вводите орган, диагноз, симптом, конфликт — получаете карточку с тканью, реле в мозге, конфликтом, метафорами, фазами, вопросами и примерами.

## Файлы
- `index.html` — само приложение (база уже встроена внутрь)
- `manifest.json`, `sw.js`, `icon-*.png` — чтобы работало как приложение и без интернета
- `gnm-table.xlsx` — исходная таблица (её можно править и загружать в приложение)

## Как обновлять базу
В приложении: вкладка «Справка» → «Выбрать файл .xlsx» → выбрать отредактированную таблицу.
Названия столбцов в первой строке листа «Органы и ткани» не меняйте. Новые столбцы можно добавлять — они появятся в карточках.
